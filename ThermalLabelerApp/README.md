# Thermal Labeler (Android + Bluetooth printer + Web print via deep link)

แอป Android (Kotlin) สำหรับพิมพ์ป้ายด้วยเครื่องพิมพ์ความร้อนผ่าน Bluetooth
โดยเว็บสามารถสั่งพิมพ์ผ่านแอปได้ทันที **โดยไม่ต้องเชื่อมต่อ/รู้จัก IP หรือพอร์ตของโทรศัพท์เลย**

## วิธีทำงานคร่าว ๆ

1. แอปเชื่อมต่อกับเครื่องพิมพ์ผ่าน Bluetooth Classic (SPP) — เชื่อมครั้งเดียว แอปจะจำไว้
2. เว็บเพจสร้างลิงก์แบบ deep link แล้วให้ผู้ใช้กด (หรือสั่งด้วย `window.location.href` จาก JavaScript):
   ```
   intent://print?text=ข้อความ&qr=ข้อมูลqr#Intent;scheme=thermalprint;package=com.example.thermallabeler;end
   ```
3. Android/Chrome เปิดแอป Thermal Labeler ขึ้นมาโดยตรง (ไม่ผ่านเน็ตเวิร์กใด ๆ)
4. แอปเชื่อมต่อเครื่องพิมพ์ตัวล่าสุดที่เคยเชื่อมไว้ให้อัตโนมัติ (ถ้ายังไม่ได้เชื่อม) แล้วพิมพ์ทันที

ไม่มี HTTP server, ไม่มี IP, ไม่มีพอร์ต, ไม่ต้องอยู่ WiFi วงเดียวกัน — ใช้ Bluetooth ล้วน ๆ

## Build APK เอง (ฟรี ไม่ต้องผ่าน Play Store)

1. ติดตั้ง [Android Studio](https://developer.android.com/studio) (ฟรี) หรือใช้ GitHub Actions ที่แนบมาให้แล้ว (`.github/workflows/build.yml`)
2. เปิดโฟลเดอร์นี้ทั้งโฟลเดอร์ด้วย **Open an existing project**
3. รอ Gradle sync
4. เสียบมือถือ (เปิด USB debugging) แล้วกด Run ▶ หรือจะ
   **Build > Build Bundle(s)/APK(s) > Build APK(s)** เพื่อได้ไฟล์ .apk ไปติดตั้งเครื่องอื่นก็ได้
   (ต้องเปิด "อนุญาตติดตั้งจากแหล่งที่ไม่รู้จัก" ในมือถือปลายทาง)

## ก่อนใช้งาน

1. จับคู่เครื่องพิมพ์ Bluetooth กับโทรศัพท์ก่อน ผ่านหน้า **การตั้งค่า > Bluetooth** ของ Android ตามปกติ
   (ปกติ PIN คือ 0000 หรือ 1234 ตามคู่มือเครื่องพิมพ์)
2. เปิดแอป Thermal Labeler → กด "รีเฟรชรายการเครื่องพิมพ์" → เลือกเครื่องพิมพ์ → กด "เชื่อมต่อเครื่องพิมพ์"
   (ต้องทำครั้งเดียวเท่านั้น แอปจะจำเครื่องพิมพ์ที่เชื่อมล่าสุดไว้ให้)
3. เปิดไฟล์ `web-example/print-test.html` บนมือถือเครื่องเดียวกับที่ลงแอปไว้ (ดับเบิลคลิกเปิดในเบราว์เซอร์
   ก็ได้ ไม่ต้องมีเซิร์ฟเวอร์เว็บ) ใส่ข้อความ/QR แล้วกด "พิมพ์ป้าย" — เบราว์เซอร์จะเปิดแอปขึ้นมาพิมพ์ให้ทันที

## รองรับเครื่องพิมพ์ 2 แบบ

ในหน้าแอปมีส่วน **"ตั้งค่าเครื่องพิมพ์"** ให้เลือกได้ว่าเครื่องพิมพ์ของคุณเป็นแบบไหน:

- **ESC/POS** — เครื่องพิมพ์ใบเสร็จทั่วไป (กระดาษม้วนต่อเนื่อง เช่น 58mm/80mm) ปรับได้แค่ความกว้างกระดาษ
  (ใช้กำหนดขนาดตัวอักษรเริ่มต้นให้เหมาะสมอัตโนมัติ)
- **TSPL** — เครื่องพิมพ์ป้าย/สติกเกอร์ (เช่น TSC, Xprinter ที่รองรับโหมด label) ต้องตั้งทั้ง
  **ความกว้าง**, **ความสูง** ของป้าย และ **ระยะ Gap** ระหว่างป้ายให้ตรงกับสติกเกอร์ที่ใช้จริง
  ไม่งั้นตำแหน่งพิมพ์จะเพี้ยน/ตัดกระดาษผิดจุด

ตั้งค่าแล้วกด **"บันทึกการตั้งค่ากระดาษ"** ครั้งเดียว แอปจะจำไว้ใช้กับทุกงานพิมพ์ต่อจากนี้
(ไม่ต้องตั้งใหม่ทุกครั้งที่พิมพ์)

### สั่ง override ค่าตั้งค่าเฉพาะบางงานพิมพ์ได้ผ่านลิงก์เว็บ

เพิ่ม query parameter ต่อไปนี้ในลิงก์ได้ตามต้องการ (ถ้าไม่ใส่ จะใช้ค่าที่ตั้งไว้ในแอป):

| พารามิเตอร์ | ค่าที่ใส่ได้ | ตัวอย่าง |
|---|---|---|
| `lang`   | `escpos` หรือ `tspl` | `lang=tspl` |
| `width`  | ความกว้าง หน่วย mm | `width=40` |
| `height` | ความสูง หน่วย mm (TSPL เท่านั้น) | `height=30` |
| `gap`    | ระยะห่างระหว่างป้าย หน่วย mm (TSPL เท่านั้น) | `gap=2` |

ตัวอย่างลิงก์พิมพ์ป้ายขนาด 40x30mm ด้วย TSPL:
```
intent://print?text=LOT%20240915&qr=https%3A%2F%2Fexample.com&lang=tspl&width=40&height=30&gap=2#Intent;scheme=thermalprint;package=com.example.thermallabeler;end
```

## เรียกจากเว็บของคุณเอง

ใส่ลิงก์แบบนี้ในหน้าเว็บ (แทนที่ `text=` และ `qr=` ด้วยค่าจริง โดยต้อง URL-encode ก่อน):

```html
<a href="intent://print?text=Cesar%20Simply%20Crafted%0ALOT%3A%20240915&qr=https%3A%2F%2Fexample.com%2Flot%2F240915#Intent;scheme=thermalprint;package=com.example.thermallabeler;end">
  พิมพ์ป้าย
</a>
```

หรือสั่งด้วย JavaScript:

```js
function printLabel(text, qr) {
  const params = new URLSearchParams();
  if (text) params.set('text', text);
  if (qr) params.set('qr', qr);
  window.location.href =
    "intent://print?" + params.toString() +
    "#Intent;scheme=thermalprint;package=com.example.thermallabeler;end";
}
```

พารามิเตอร์ที่รองรับ:

| พารามิเตอร์ | ความหมาย |
|---|---|
| `text` | ข้อความที่จะพิมพ์ (รองรับหลายบรรทัดผ่าน `%0A`) |
| `qr`   | ข้อมูลสำหรับสร้าง QR code (ใส่หรือไม่ใส่ก็ได้) |
| `lang` | (ไม่บังคับ) `escpos` หรือ `tspl` — ถ้าไม่ใส่ ใช้ค่าที่ตั้งไว้ในแอป |
| `width`, `height`, `gap` | (ไม่บังคับ) override ขนาดกระดาษ/ป้ายเฉพาะงานนี้ หน่วย mm — ดูหัวข้อ "รองรับเครื่องพิมพ์ 2 แบบ" ด้านบน |

## ข้อจำกัดที่ควรรู้

- ต้อง**ติดตั้งแอปนี้ไว้ในเครื่องก่อน** ลิงก์ deep link ถึงจะเปิดแอปได้ ถ้ายังไม่ได้ลง Chrome จะแจ้งเตือน
  ว่าเปิดแอปไม่ได้เฉย ๆ (ไม่พังหน้าเว็บ)
- ใช้ได้เฉพาะบนมือถือ Android เครื่องเดียวกับที่ลงแอปและจับคู่เครื่องพิมพ์ไว้ (เพราะเป็นการเปิดแอปในเครื่อง
  เดียวกัน ไม่ใช่ยิงข้าม device)
- **ภาษาไทย**: เครื่องพิมพ์ thermal บางรุ่นไม่รองรับฟอนต์ไทยผ่านคำสั่งข้อความตรง ๆ (ต้องใช้ codepage
  เฉพาะของรุ่นนั้น) ถ้าพิมพ์ภาษาไทยแล้วเป็นตัวอักษรมั่ว วิธีแก้ที่ชัวร์ที่สุดคือ render ข้อความเป็นรูปภาพ
  (bitmap) แล้วส่งเป็นคำสั่งพิมพ์รูปแบบ raster (`GS v 0`) แทนคำสั่งข้อความ — ถ้าต้องการโค้ดส่วนนี้เพิ่ม
  แจ้งได้ ทำเป็นโมดูลเสริมให้ได้
- แอปนี้เขียนแบบ minimal เพื่อให้ build เองและปรับแก้ต่อได้ง่าย
